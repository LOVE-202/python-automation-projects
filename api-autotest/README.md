# 接口自动化测试框架

这是求职简历中的主项目。目标是从零实现一个可维护、可扩展的接口自动化测试框架。

## 规划功能

- 使用 pytest 组织测试用例
- 使用 requests 封装统一的接口请求客户端
- 使用 yaml 管理测试数据
- 登录后自动提取 token 并传递到后续用例
- 支持环境切换
- 使用日志记录执行过程
- 使用 Allure 生成测试报告
- 使用 Git 管理版本并上传 GitHub

## 当前进度

- 仓库初始化完成
- 第 1 章 Python 基础完成（变量和类型、字符串和列表、条件判断和循环、函数、类和对象、异常处理和 JSON）
- 第 2 章 pytest 入门完成（测试发现、assert 断言、运行多个文件、按名称筛选）
- 第 3 章 requests 接口调用完成（GET、GET 带参数、POST、PUT、DELETE、状态码、json 解析和断言）
- 第 4 章 pytest 与 requests 结合完成（把请求脚本升级为正式测试用例，使用 pytest 自动断言）
- 第 5 章 fixture 与测试数据隔离完成（conftest、autouse、reset 接口、可重复执行的增删改用例）
- 第 6 章 pytest 参数化完成（parametrize、一个测试函数跑多组数据、接口参数化测试）
