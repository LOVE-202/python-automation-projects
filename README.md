# Python 自动化测试项目集

面向 Python 自动化测试岗位的求职项目仓库，包含两个可以写进简历的项目。

## 项目一：接口自动化测试框架

目录：`api-autotest`

技术栈：Python、pytest、requests、PyYAML、Flask、Allure、Git

这是主项目，会从零搭建一个数据驱动的接口自动化测试框架，并自己实现一个简单的被测系统。

## 项目二：Web UI 自动化测试框架

目录：`webui-autotest`（后续开始）

技术栈：Python、Playwright、pytest、Allure

作为第二项目，覆盖登录、搜索、加购等核心流程，包含失败截图和测试报告。
